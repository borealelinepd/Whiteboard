# White Board

Run counter, per-well stage count and Days/Nights XO notes for the wireline crew.

Live app: https://borealelinepd.github.io/whiteboard/

- Install on a PC: open the link in Microsoft Edge, then ... menu > Apps > Install White Board.
- Works without internet after the first open. Updates load the next time it's opened with a connection.
- Help: https://borealelinepd.github.io/whiteboard/help.html (also under More > Help in the app).
- Crew data is saved on each PC only. Nothing typed into the app is stored in this repo.

To update: upload the new `index.html` here (Add file > Upload files > Commit changes).
